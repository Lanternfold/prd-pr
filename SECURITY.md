# Security

PRD→PR is a small open-source developer tool. It runs locally and orchestrates Git, CLI tools, and (optionally) Cursor and GitHub. Treat unexpected behavior around credentials, workspace paths, and subprocesses as security-relevant.

## Reporting a vulnerability

Do **not** open a public GitHub issue, discussion, or pull request for an undisclosed vulnerability.

This repository does not currently publish a security email, dedicated intake service, or other private contact. It also does not currently have GitHub private vulnerability reporting configured.

Once GitHub private vulnerability reporting / a security advisory intake is enabled on this repository, use that mechanism to report vulnerabilities privately.

If private reporting is not yet available in the GitHub Security tab, keep the details private until it is enabled rather than disclosing them in a public issue.

When you can file privately, include enough information to reproduce the issue (affected version or commit, environment, and steps).
